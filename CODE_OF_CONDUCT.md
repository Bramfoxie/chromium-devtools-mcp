# Code of conduct

## Our standard

This project is a place for respectful technical work. Be courteous, assume good intent and keep feedback about the work, not the person. Harassment, discrimination, personal attacks and publishing other people's private information are not accepted.

## Scope

This applies to issues, pull requests, discussions and any other space where someone represents the project.

## Enforcement

Report a concern through a GitHub issue, or privately to the owner at me@bramfoxie.com. The owner reviews reports, may edit or remove contributions and may restrict participation for conduct that breaks this standard.
