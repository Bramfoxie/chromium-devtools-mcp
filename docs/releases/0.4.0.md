Inspect event listeners and focus DOM snapshots on the parts of a page that matter.

### Added

- `event_listeners` lists the event types and capture, passive and once options registered directly on an element, including elements in frames and shadow roots. It does not return handler code or identifiers.
- `dom_snapshot` accepts a `mode` of `interactive`, `forms`, `landmarks` or `text`, in addition to the default `all`. Filtered snapshots retain named ancestors and frame owners for context and apply to iframe sections too. An explicit `mode` takes precedence over `interactiveOnly`.

- `popup_list` lists available popups opened by an owned tab, optionally waits for IDs absent from a baseline, and reports when its 100-item result limit truncates matches.
- `window_list` lists distinct browser windows containing session tabs and their bounds without focusing them.

### Changed

- Attach diagnostics log why a browser debugging port file cannot be used, to help diagnose connection failures.
- When the operating system refuses to read the browser's `DevToolsActivePort` file (on macOS, an app without access to another app's data), attach and `doctor` now say which file cannot be read and how to fix it (Full Disk Access for the app that starts the server, or starting the daemon from a terminal that has access). Before, they reported that remote debugging is not enabled.
- The release CI gate uses the latest attempt of each CI workflow run when deciding whether a commit can be published.
- `input_scroll` can experimentally observe trusted wheel events in the document under the requested point, including nested frame sessions. Observation does not prove which request caused an event or that scrolling occurred. Delivery remains unconfirmed when the probe is unavailable or domain rules are active.
- Real Chrome integration coverage now includes filtered snapshots, wheel observation, and typing, key input and scroll into view in nested cross-site frames.

### Fixed

- `event_listeners` releases the handler objects the browser returns for each listener; before, they stayed in the page until navigation.
- The wheel observation in `input_scroll` reuses one isolated world instead of creating a new one on every call.
- The release CI gate rejects malformed run data from `gh` and retries instead of treating it as a result.
