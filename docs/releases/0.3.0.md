Edit the DOM and CSS of a page, find elements by role or text, wait for them, and safer defaults: block lists, local network protection and a notice on page content.

### Added

- `dom_edit` changes one element without JavaScript: set or remove an attribute, replace text or HTML, remove the element, or add, remove or toggle a class. The result carries the previous value so a change can be reverted.
- `css_edit` changes styles without JavaScript: `set_style` edits the inline style of an element, `add_rule` adds a rule to a style tag the tool owns (in the shadow root when the target is inside one), and `remove_rule` removes it by the id `add_rule` returned. A property or rule the browser does not accept fails the call and changes nothing.
- Locators: any element target can be `{ "locator": { "role": "button", "name": "Save" } }` or `{ "locator": { "text": "Order confirmed" } }` instead of a `uid` or a CSS selector. Fields, labels and placeholders are found through their accessible name. Several matches are an error with their count, `nth` picks one, `exact` matches the whole text.
- `timeoutMs` on `click`, `input_click`, `input_hover`, `input_type`, `input_key`, `input_select` and `fill_form`: the call waits for the element to be visible, enabled and not covered before it refuses.
- `safety.deniedDomains` (`--denied-domains`, `CHROMIUM_DEVTOOLS_MCP_DENIED_DOMAINS`) blocks hosts with the same rules as `safety.allowedDomains`, and a denial wins over an allowed entry.
- `safety.allowPrivateNetworks` (`--allow-private-networks`, `CHROMIUM_DEVTOOLS_MCP_ALLOW_PRIVATE_NETWORKS`), see Changed.
- `css_inspect` takes `forceStates` (`hover`, `focus`, `active` and others) to read the computed style and the matched rules of an element in that state. The states are removed again before the call returns.
- `dom_selector` turns an element into a CSS selector and a role locator that find it again. The selector prefers ids, test attributes and stable classes, is checked to match only that element, and carries a shadow host chain or the iframe selector when the element is inside one.
- `a11y_snapshot` lists the accessibility tree as structured nodes with role, name, value, states and a `uid`, filters by interactive nodes, role or subtree, and counts the controls that have no accessible name.
- `network_har` saves the requests of a tab as a HAR 1.2 file that DevTools and other tools open. URLs and headers keep the redaction of `network_requests` and there are no bodies.
- `downloads` lets a tab save the files it downloads into a private directory (`allow`, `deny`), lists them and waits for the next one to finish. The browser can write only inside the artifacts directory of the daemon.
- MCP resources: the tabs of the session are offered as `browser://tab/<id>/text`, `/screenshot` and `/console`, for clients that attach resources to a conversation. They only read and carry the same untrusted notice.
- `tools` and `excludeTools` (`--tools`, `--exclude-tools`) choose the tools the server offers, by name or by group (`inspection`, `input`, `emulation` and others). `--tools=slim` offers 17 tools to save context. A tool that is left out is not listed and cannot be called, and a name that does not exist stops the server.
- `auditLog` (`--audit-log`) appends one JSON line per tool call to a file: tool, tab, redacted address, summarized arguments, outcome and duration. What the agent types or runs is kept only as its length and a short fingerprint, and secrets are redacted.
- `page_wait` waits for a quiet document (`domQuietMs`) and for a network response by URL, regular expression and status (`responseUrl`, `responseUrlRegex`, `responseStatus`).
- `chromium-devtools-mcp config` prints the effective configuration, which source set each value (default, file, env or flag) and whether the config file exists, and reports an invalid configuration with exit code 2.

### Changed

- Under `safety.allowedDomains` or `safety.deniedDomains`, `network_mock` adds a rule only for a pattern that names a host the rules accept (`https://api.example.com/*`), and cookie reads (`storage_read`) are refused for a page outside the rules. A pattern such as `*` is refused while a list is set.
- Local and private network addresses are blocked by default. `new_tab`, `page_navigate` (also back and forward), the address a navigation ended on after redirects, and `lighthouse_audit` refuse `localhost`, loopback, `10.x`, `172.16` to `172.31`, `192.168.x`, link-local addresses such as the cloud metadata address, and the IPv6 forms of these. To work on a local server, pass `--allow-private-networks`, or list the host in `safety.allowedDomains` (for example `localhost:3000`), which is still opened. Tabs you opened yourself in attach mode are not affected, and links a page follows by itself are not checked.
- Click and input tools wait up to 2 seconds by default when an element is disabled, hidden or covered, so such a call refuses after 2 seconds instead of at once. Pass `timeoutMs: 0` for the earlier behavior.
- The text of a tool result that can hold page content starts with an `untrusted` key that tells the model to treat the values as data, never as instructions. The `structuredContent` is unchanged, and the server instructions say the same.
- `dom_edit` with `set_html`, `remove`, or `set_attribute` for a script capable attribute (`on*`, `srcdoc`, `javascript:` and similar values), and `css_edit` with a value that makes the page fetch an address (`url(`, `@import`), ask for confirmation when `safety.confirmDangerous` is on.
- The session settings sent to the daemon carry the two new safety fields. After updating, run `chromium-devtools-mcp daemon stop` once, because a daemon of version 0.2.0 that is still running rejects them.
