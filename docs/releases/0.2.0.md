Performance traces, heap snapshots, screen recording, Lighthouse audits, passkey testing and more input tools.

### Added

- Input tools: `input_drag` (elements or points, native HTML5 drag and drop), `fill_form` (many fields in one call), and `input_click` with a `point` for agents that work from screenshots.
- Performance tools: `perf_trace_start` and `perf_trace_stop` save a trace the Performance panel opens and report Web Vitals, long tasks and requests. `heap_snapshot` reports memory by kind of object and detached DOM nodes.
- `screencast_start` and `screencast_stop` record a tab into an MP4 file when `ffmpeg` is installed, or into JPEG frames when it is not.
- `lighthouse_audit` runs the Lighthouse installed on the machine and reports scores and failed checks.
- `emulate_geolocation`, `webauthn` (virtual authenticators and credentials), `pwa_info` and `bring_to_front` (only with `allowFocus`).
- Commands: `daemon status`, `daemon stop`, `daemon logs` and `doctor`.
- `wsEndpoint` setting to attach to a browser at an explicit loopback address.
- `screenshot` reports `pixelRatio` to convert an image pixel to a CSS pixel.

### Fixed

- A tab that stopped answering no longer holds the frame list request for 30 seconds, it fails after 10.
- The daemon rejects a malformed `safety.allowedDomains` entry in a session instead of accepting a rule that never matches or matches too much.

### Changed

- `safety.allowedDomains` is checked against the frame of every target of a call, and frames that inherit an origin (`about:blank`, `about:srcdoc`) are judged by the origin they really have.
- Files that tools save go into a private `artifacts` directory next to the daemon log and are removed after a day.
- Optional programs run without a shell, with a minimal environment, and are stopped with everything they started when a call is cancelled.
- A trace keeps only the events of the frames of its tab. Redirects of the Lighthouse browser are not checked against `safety.allowedDomains`.
- CI and the release run on `ubuntu-26.04`, and the package no longer ships type declarations.
