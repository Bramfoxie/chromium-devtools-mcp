Two new page reading tools, more clients and browsers, and a stricter private network guard.

### Added

- `page_extract` lists the links, headings, meta tags and forms of the top document of a tab, with the number of items found and a flag when a list was cut. Addresses have secrets in them hidden, the values of form controls are never read, and meta tags whose name looks like a secret show `[hidden]`.
- `find_in_page` finds visible text in the top document of a tab, also inside open shadow roots, and lists each match with its context and viewport position. With `scroll: true` it brings a match to the middle of the view without taking the focus; that is the only case that changes the page, so read-only mode refuses it.
- The installer writes the server entry for Claude Desktop, Windsurf, Gemini CLI, VS Code and VS Code Insiders (`--client claude-desktop|windsurf|gemini-cli|vscode|vscode-insiders`). `--client all` still means the first four clients. These entries follow the locations the clients document and were tested with a fake file system, not inside the clients.
- The `browser` setting accepts `chrome-beta`, `chrome-dev`, `chrome-canary`, `chromium` and `edge`, each with its install locations and user data directory. Only stable Chrome has been run against the server.
- `docs/troubleshooting.md` collects the common setup problems.

### Changed

- With `safety.allowPrivateNetworks` off, a public name is looked up before `new_tab`, `page_navigate` and `lighthouse_audit` open it, and again for the address a navigation ended on. The call is refused when the name resolves to a local or private address. The check is best effort: a name that does not exist or a lookup that fails is let through, answers in `198.18.0.0/15` (used by proxy and VPN tools) are ignored, and a name can still change its answer after the lookup.
- `localhost.localdomain`, `*.localdomain`, `ip6-localhost` and `ip6-loopback` count as local names.

### Fixed

- A domain rule written as a numeric or IPv6 address in another form, such as `127.1` or `[0:0:0:0:0:0:0:1]`, never matched the address in its usual form, so a `safety.deniedDomains` entry written that way did not block it. Rules are now compared in the canonical form, and a numeric rule that is not a valid address is rejected at startup.
- The trace test waits for the layout shift before stopping the trace, so it no longer fails on a busy machine.
