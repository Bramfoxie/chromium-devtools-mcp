### Added

- `page_history` lists bounded navigation history around the current entry and redacts secrets in addresses.

- `page_navigate` supports `action: "stop"` to stop loading the selected tab without waiting for a load event.

### Fixed

- Back and forward navigation check whether a history entry resolves to a private network address before opening it.

- `page_navigate` rejects `ignoreCache` for actions other than reload instead of silently ignoring it.
