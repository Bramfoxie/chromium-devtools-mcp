### Added

- `network_requests` reports available DNS, connection, TLS, send and time to response headers. Unavailable phases are omitted.

- `screenshot` accepts `maskElements` to cover selected elements. Masking is best effort; inspect the image before sharing.

- `page_extract` reads bounded table rows and cells, excluding form control values and reporting truncation.

- `page_history` lists bounded navigation history around the current entry and redacts secrets in addresses. `page_navigate` can open an entry by its index with `action: "history"`.

- `page_navigate` supports `action: "stop"` to stop loading the selected tab without waiting for a load event.

### Fixed

- A cancelled storage write directs callers to inspect storage before retrying.

- HAR export clears captured requests only after the file is saved, preserving requests added or updated during the save and retaining dropped counts after a failed save.

- Cookie clearing uses one initial snapshot for both deletion and its result count, and cookie writes report completed requests if reading the final count fails.

- Cookie set, remove and clear actions report completed requests when a later browser request fails, so callers can check the resulting storage before retrying.

- Trace integration tests attempt to stop active recordings after failures so later cases can run independently.

- A paused cross-site iframe gets one more resume attempt after a CDP timeout while its session remains attached.

- Emulation changes and rollback stop when the browser session resets instead of modifying replacement session state.

- Geolocation permission changes stop on session reset without applying cleanup to the replacement session.

- Failed console or network capture setup releases event subscriptions already established by that attempt.

- Capture setup from a closed tab or reset session cannot remove subscriptions from its replacement.

- Frame refresh invalidates element IDs when it detects a changed frame URL.

- Late frame discovery and subscriptions cannot restore frame state after a tab closes or a session resets.

- Frame discovery retries when events overlap a read and does not overwrite a newer tree with a late older result.

- Frame event subscriptions start before the initial tree read to avoid missing changes during discovery.

- Dialog checks stop when the tab closes or the session resets during subscription or setup.

- Element IDs from a removed tab or session cannot resolve to new elements after the state is recreated.

- Element IDs from one tab cannot select a different element in another tab of the same session.

- `page_navigate` rejects a URL supplied with another action instead of ignoring it.

- `new_tab` reports no load wait for a blank tab instead of claiming a load event occurred.

- `page_wait` rejects selector state when waiting for another condition instead of ignoring it.

- A late focus emulation response no longer restores state or allows an action to continue after a tab closes or a session resets.

- Concurrent download waits without an ID do not return the same finished download twice, and concurrent file lookups do not assign one file to multiple downloads.

- Downloads in separate directories no longer block each other's file lookups.

- A download keeps its original save directory when downloads are enabled again.

- Download events arriving during a settings change are recorded without guessing their save path, and overlapping changes are refused.

- An overlapping download setting change is refused before creating an unused directory.

- Download setting changes stop if the tab state is removed during preparation.

- Download event subscriptions can be established again after a session reset.

- Waiting for a download ends when the tab closes or the session resets, including during file lookup.

- Browser attachment stops promptly when cancellation arrives during endpoint discovery, even if a file read or probe is still pending.

- Browser endpoint discovery rejects empty browser IDs, credentials, queries and fragments in port file and HTTP results.

- Managed browser startup checks cancellation after executable discovery and process creation, and removes its abort listener when startup ends.

- Managed browser startup accepts only local browser WebSocket addresses without queries or fragments, on the configured debugging port or a nonzero browser selected port when configured as zero.

- Explicit browser WebSocket addresses and managed startup correctly handle the default WebSocket port when it is written as `:80`.

- Pending tab listings report a closed session when the browser responds or fails after that session closes.

- Popup discovery reports a closed opener when the browser responds or fails after that tab closes.

- Window lookup reports a closed tab when the browser responds or fails after that tab closes.

- Page extraction runs in an isolated world so page overrides do not run during a read-only extraction.

- Screenshot masks determine the element frame from the DOM snapshot, including pierced selectors and saved element IDs, and reuse snapshots within each measurement pass.

- Selected element masking checks same process frame geometry and refuses cases whose coordinates cannot be covered reliably; measurement work on large trees is bounded.

- Screenshot mask measurement runs in an isolated world and includes snapshot bounds for shadow and pseudo element content.

- Screenshot masks include the bounds of visible descendant elements and text that extend outside a selected element.

- Table extraction reads text without cloning custom elements or invoking their constructors.

- History navigation stops waiting for DNS when its timeout expires and cannot navigate later after cancellation.

- Back and forward navigation check whether a history entry resolves to a private network address before opening it.

- `page_navigate` rejects `ignoreCache` for actions other than reload instead of silently ignoring it.

### Verification

- Before the version bump, lint, typecheck, build and the full test suite passed locally on macOS, Ubuntu and Windows with Node 24 and Node 26, with platform specific tests skipped where unavailable.

- The trace interaction test passed five focused runs each on macOS and Ubuntu with low priority CPU load. This limited sample does not rule out intermittent timing failures.

- `npm audit` reported no known vulnerabilities on 2026-11-12, including development dependencies.

- Before the version bump, a locally packed build was installed with scripts disabled in temporary projects and its CLI help ran on macOS, Ubuntu and Windows with Node 24.
