### Added

- Find slow parts of a request with DNS, connection, TLS, send and time to response headers in `network_requests`. Unavailable timings are omitted.
- Cover selected elements in screenshots with `maskElements`. Masking is best effort, so inspect the image before sharing it.
- Extract bounded table rows and cells with `page_extract`. Form control values are excluded and truncation is reported.
- Explore navigation entries with `page_history` and open one by index using `page_navigate` with `action: "history"`. Secrets in addresses are redacted.
- Stop a page load with `page_navigate` and `action: "stop"` without waiting for a load event.

### Fixed

- Cookie operations report completed work when a later request fails. A clear operation reports an uncertain count if concurrent additions would make it negative.
- HAR export keeps captured requests until the file is saved, including requests added or updated during the save.
- Cancelled storage writes direct callers to inspect storage before retrying. Cancelled handler startup also handles a later rejection.
- Screenshot masks cover visible descendant content and use frame geometry more reliably. Cases that cannot be covered reliably are refused, and measurement work on large trees is bounded.
- Table extraction avoids invoking custom element constructors and runs in an isolated world, so page overrides do not run during a read-only extraction.
- History navigation respects timeouts during DNS lookup and checks private network restrictions before opening back or forward entries.
- Navigation and wait tools reject options that do not apply to the selected action. A blank new tab no longer reports a load wait that did not happen.
- Download waits, file lookup and settings changes handle concurrent operations and session resets more reliably. Downloads retain their original save directory when downloads are enabled again.
- Frame discovery, element IDs, capture subscriptions, dialogs, focus emulation and geolocation no longer restore stale state after a tab closes or a session resets.
- Browser attachment and managed startup respond to cancellation more reliably and validate discovered WebSocket addresses. Explicit default WebSocket ports are handled correctly.
- Tab, popup and window lookups report when their session or tab closes while a request is pending.
- A paused cross-site iframe gets another resume attempt after a CDP timeout while its session remains attached.

### Known limitations

- Background tabs may not reliably deliver trusted wheel input to cross-site frames. Delivery can remain unconfirmed.
- A cookie clear count can be inaccurate if cookies change concurrently, even when the reported count is nonnegative.
