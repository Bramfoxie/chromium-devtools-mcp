First release of chromium-devtools-mcp, an MCP server that lets AI agents control Chrome through the DevTools Protocol.

### Added

- Attach mode for a running Chrome and managed mode with a persistent profile, headed or headless.
- Per-user daemon shared by all MCP clients, with an isolated session and an optional isolated browser context per client.
- Tab tools: `list_tabs`, `list_sessions`, `select_tab`, `new_tab`, `close_tab`.
- Page tools: `page_info`, `page_navigate`, `page_wait`, `page_dialogs`, `page_metrics`, `page_pdf`.
- Inspection tools: `dom_query`, `dom_snapshot`, `css_inspect`, `js_evaluate`, `screenshot`, with shadow DOM and cross-site iframe support.
- Input tools: `click`, `input_click`, `input_hover`, `input_type`, `input_key`, `input_scroll`, `input_select`, `input_upload`.
- Observation tools: `console_logs`, `network_requests`, `network_response_body`.
- Network mocking: `network_mock`.
- Storage tools: `storage_read`, `storage_write`.
- Emulation tools: `list_devices`, `emulate_device`, `emulate_media`, `emulate_network`, `emulate_locale`.
- Safety options: `safety.readOnly`, `safety.allowedDomains`, `safety.confirmDangerous`.
- `install` command for Claude Code, Cursor, Codex and Cherry Studio.
